{# FormField — design system §5, R-F03-01 / R-F03-02. Membungkus satu field WTForms: label terhubung, input, pesan error di dekat field, dan atribut aksesibilitas. Kenapa partial dan bukan menulis markup per field: `aria-describedby` harus menunjuk id pesan yang benar-benar ada. Kalau id pesan ditulis manual di tiap template, cepat atau lambat ada yang salah ketik dan pesan errornya tidak pernah terbaca pembaca layar. Catatan render: `autofocus=false` akan menjadi atribut `autofocus="false"` yang justru MENYALAKAN autofocus (kehadiran atribut sudah cukup). Karena itu atribut hanya ditambahkan saat benar-benar diminta. Parameter: field objek WTForms hint string|null petunjuk tetap (dipakai saat tidak ada error) autocomplete, type, autofocus opsional #} {% macro form_field(field, hint=None, autocomplete=None, type=None, autofocus=False) -%} {%- set punya_error = field.errors|length > 0 -%} {%- set error_id = field.name ~ "-error" -%} {%- set hint_id = field.name ~ "-hint" -%} {#- Error lebih dulu: bila keduanya ada, pembaca layar membacakan yang salah. #} {%- set deskripsi = error_id if punya_error else (hint_id if hint else None) -%} {%- set atribut = { "type": type or field.type|lower, "aria-invalid": "true" if punya_error else "false", } -%} {%- if autocomplete -%}{%- set _ = atribut.update({"autocomplete": autocomplete}) -%}{%- endif -%} {%- if deskripsi -%}{%- set _ = atribut.update({"aria-describedby": deskripsi}) -%}{%- endif -%} {%- if autofocus -%}{%- set _ = atribut.update({"autofocus": "autofocus"}) -%}{%- endif -%}
